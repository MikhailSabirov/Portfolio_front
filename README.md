# Портфолио — Михаил Сабиров

Статический сайт: index.html + three.min.js + папка img. Сборка не нужна.

## Как выложить на GitHub Pages
1. Создайте репозиторий, например `portfolio` (или `<ваш-логин>.github.io`).
2. Загрузите в корень репозитория всё содержимое этой папки.
3. Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<логин>.github.io/portfolio/`.

## Что поменять
- Контакты: в index.html найдите `const CONTACTS=` и впишите свой Telegram, e-mail и GitHub.
- Проекты и боты: массивы `WORKS` и `BOTS` в index.html (название, описание, статус, картинки).
- Картинки лежат в `img/`, формат 16:10, имя файла без `.jpg` указывается в поле `img`.
